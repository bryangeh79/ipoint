## 1. Frozen sequence and operating rules

`P7-S1 → P7-S2 (Admin Identity/MFA/Session/RBAC/Market) → P7-S3 (Admin Web Shell) → P7-S4 (Dashboard) → P7-S5 (Member/Merchant/KYC) → P7-S6 (Configuration) → P7-S7 (Manual MCP/iPoint) → P7-S8 (Agent/Phase 6 Operations) → P7-S9 (Audit Viewer/Basic Reports) → P7-S10 (Integration and Delivery)`.

P7-S4 and P7-S5 may overlap only after P7-S3 acceptance and only with non-overlapping owners. Frozen-owner remediation uses its owning phase, a separate branch/worktree, dedicated ledger/auth/permission/migration/transaction-state commits, independent regression, and Command Center acceptance before the consuming Phase 7 work. Recommended agent counts are maxima for a separately authorized dispatch, not standing authorization.

### Recommended Phase 7 CI job set

1. `quality`: format check, ESLint, strict TypeScript, encoding audit, forbidden debug/generated-artifact check.
2. `build`: API, Admin Web, shared UI, design tokens, API client; PWA manifest/service-worker validation.
3. `unit`: all workspaces plus targeted Admin identity, permission, route, metric, state-machine, decimal/timezone, masking, and error mapping tests.
4. `database`: clean accepted-baseline migration apply, checksum, seed twice, schema drift, forward compatibility, constraints/triggers, real PostgreSQL integration.
5. `api-integration`: registered `/api/v1` routes, OpenAPI parity, typed DTO/error contracts, positive/negative RBAC/market matrix, idempotency/concurrency/rollback.
6. `admin-security`: MFA/session/revocation/reuse, step-up, secret/redaction/privacy/log scans, CORS/security headers for actual methods, audit-of-audit.
7. `frozen-domain-regression`: Phase 1 MCP/Merchant; Phase 2 Member/KYC; Phase 3 Wallet/Reward; Phase 4 Transaction; Phase 5 B/C/D; Phase 6 Redemption—selected by changed owner and always full at P7-S10.
8. `financial-invariants`: MCP/iPoint/refund/commission exact decimal, append-only/exact-opposite, projection/ledger atomicity, Maker/Checker, concurrent/retry behavior.
9. `admin-e2e-desktop`: real API/PostgreSQL Playwright for routed critical flows, deep links/back/refresh, blocked gates, session/market changes.
10. `admin-e2e-mobile-pwa`: representative viewports, offline/stale/read-only policy, proof of no privileged action/offline queue/background replay/sensitive caching.
11. `accessibility`: axe with zero critical/serious violations plus keyboard/focus/labels/contrast/reduced-motion assertions; manual evidence checklist retained.
12. `dashboard-report-performance`: fixture correctness, bounded dates/cursors, `EXPLAIN`/latency thresholds, freshness/stale/unavailable, no first-page/fabricated/cross-currency totals.
13. `dependency-secret-scan`: configured dependency audit, committed-secret scan, client bundle/source-map sensitive-string scan; no environment values printed.
14. `delivery-evidence`: exact SHA/test counts/artifact hashes, route-permission zero-drift manifest, OpenAPI diff, scoped `git diff/status`, blocked-capability inventory.
