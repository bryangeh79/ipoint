# iPoint

iPoint 是一个面向会员、商家、代理与平台运营团队的多市场消费回馈平台。

## 当前阶段

工程正式启动，采用自动化交付模式：

- ChatGPT：产品、架构、任务拆解与最终验收
- Codex CLI：主工程执行器
- Gemini CLI / Pro：独立审查与测试补充
- GitHub：任务、代码、CI、PR 与交付记录的唯一工程事实来源

## 交付原则

1. 先完成可运行版本，再持续完善。
2. 未经确认，不改变已锁定的商业规则、佣金、回馈率、兑换率、法律定位或资金流程。
3. 所有 UI/UX 必须遵循 iPoint Product Design System V1.0。
4. 禁止直接在 `main` 开发；日常开发进入 `develop` 或功能分支。
5. MCP、iPoint 与佣金必须使用不可篡改的账本记录与完整审计链。

## 第一交付目标

完成以下核心闭环：

会员注册 → 商家入驻 → MCP 充值 → 商家扫码交易 → MCP 扣除 → 每日 iPoint 发放 → Admin 审核与审计。
